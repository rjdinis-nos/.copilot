GitHub Copilot Customizations

Collection of custom agents, prompts, and instructions to supercharge your GitHub Copilot experience.

To Install:

  • Click the VS Code install button for the instruction you want to use
  • If clicking the button does nothing, make sure Visual Studio Code is installed.

To manual apply:

  • Download the *.instructions.md file and manually add it to your project's instruction collection
  • Copy these instructions to your .github/copilot-instructions.md file in your workspace
